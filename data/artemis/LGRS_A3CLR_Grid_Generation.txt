# This program is designed to create lunar Grid Reference System (LGRS)
# navigational grids for the Aretmis III Candidate Landing Regions 
# (A3CLR).

# LGRS is a  grid system for lunar navigation based on a 25km globalized
# grid. It is smillar in design and use to the Military Grid Reference 
# System (MGRS). 

# To meet NASA requerments to have a highly condesed coorodnate 
# strucute to limited the cognitive impact to the Artemis Astronaughts,
# LGRS coodoante are condesed to 6-charicters using a 1km grid imposed 
# within the LGRS 25km grid, labled alphabetically then and truncated 
# to a 10m percision.

# The following god utalized the LGRS_Grid_Generation_mk6.py and
# LGRS_Coordinate_Conversion_mk6.py to generate the grids for the A3CLR
# and the landing regions of the Apollo Missions.

# =====================================================================

    # mv ${dir_o} ../Data_Release2_ACC/.

    fi
