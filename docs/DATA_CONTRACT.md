# Data contract: engine → dashboard

This file describes every JSON file the science engine writes and every field in it. The dashboard reads static files only (no backend needed for curated sites). Custom coordinates will come from a FastAPI endpoint returning the same per-site shape (section 5).

Generated by `python scripts/precompute.py` into `out/`. Validation results come from `pytest` into `out/validation_report.json`.

## 0. Conventions

| Thing | Convention |
|---|---|
| Coordinates | MOON_ME (mean-Earth) frame, planetocentric latitude, **east-positive longitude 0–360**. Same frame as LOLA DEMs and JPL Horizons. |
| Heights | metres above the 1737.4 km reference sphere |
| Azimuth | degrees clockwise from local north (N=0, E=90, S=180, W=270) |
| Elevation | degrees above the local horizontal plane (sphere normal), **apparent** (light time + stellar aberration), no refraction (airless) |
| Time | UTC ISO-8601 strings ending in `Z` (events) or without `Z` (window bounds; also UTC) |
| Visible fraction | fraction of the target's disc above the terrain horizon, 0–1 (horizon treated as flat across the disc) |
| Mast height | observer height above ground, metres; precomputed for **0, 2, 10 m**, default **2 m** |
| Compact integer arrays | `*_cdeg` = centi-degrees (÷100), `*_mdeg` = milli-degrees (÷1000), `*_pm` = per-mille (÷1000) |

Metric definitions (match Gläser et al. 2018 / Mazarico et al. 2011; label them in the UI):
- **Average illumination** (`avg_fraction_pct`) = mean visible fraction of the solar disc over time.
- **Solar visibility** (`any_visible_pct`) = % of time any part of the Sun is visible.
- **Earth visibility** = % of time any part of Earth's disc is visible. PGDA calls this "slightly optimistic for radio links" — say so in the UI.
- These two differ by ~5 pp at the same spot; mixing them up makes numbers look wrong.

## 1. `out/sites/index.json`

```json
{ "generated_utc": "...", "sites": [ SiteHeadline, ... ] }
```

`SiteHeadline`:

| Field | Type | Meaning |
|---|---|---|
| `id` | string | stable key, also the per-site filename |
| `name` | string | display name |
| `group` | `"artemis"` \| `"polar"` \| `"mission"` \| `"apollo"` | catalogue group. `artemis` = Artemis III candidate region, represented by its best-lit landable point |
| `country` | string \| null | for mission sites |
| `lat`, `lon` | number | requested coordinates |
| `sun_avg_pct`, `sun_any_pct` | number | 18.6-yr average illumination / solar visibility at 2 m |
| `earth_any_pct` | number | 18.6-yr Earth visibility at 2 m |
| `both_pct` | number | % of time Sun **and** Earth both (any part) visible |
| `max_dark_h` | number | longest continuous solar darkness over 18.6 yr, hours (hourly resolution) |
| `far_side` | bool | Earth never clears the **open** horizon (pure geometry, far side) → "Earth never rises here (far side)" |
| `earth_blocked_by_terrain` | bool | Earth is above the open horizon at times but local terrain hides it all the time → "Earth is hidden by terrain here" (a different state from far side) |
| `has_mission` | bool | site has a `mission_replay` block |
| `has_uncertainty` | bool | site has an `uncertainty` block (DEM error clones) |

## 2. `out/sites/<id>.json` (one per site)

Top level:

| Field | Type | Meaning |
|---|---|---|
| `id`, `name`, `group`, `country`, `note`, `source` | | catalogue metadata; `source` = where the coordinates come from |
| `requested` | `{lat, lon}` | coordinates as catalogued |
| `snapped` | `{lat, lon, ground_m}` | observer actually used: nearest DEM pixel centre and its height (grid-point evaluation, as in the literature) |
| `dem` | `{near, near_res_m, far, far_res_m, far_km}` | terrain products used: near field (to 20 km) and far field (to `far_km`) |
| `default_mast_m` | number | 2 |
| `horizons` | `{ "0": Horizon, "2": Horizon, "10": Horizon }` | terrain horizon per mast height |
| `longterm` | `{ "0": LongTerm, "2": ..., "10": ... }` | 18.6-yr hourly statistics per mast height |
| `window` | `{start_utc, stop_utc}` | planning window covered by `events` and `track` (2026-11-01 → 2028-01-01) |
| `events` | `{ "0": [Event], "2": [Event], "10": [Event] }` | rise/set events in the window, sorted by time |
| `track` | Track | 3-hourly Sun/Earth positions + visible fraction in the window (mast 2 m) |
| `sensitivity` | Sensitivity \| null | "move N m to gain X" scan (sites with \|lat\| ≥ 75° only) |
| `region` | Region \| null | Artemis III sites only: USGS LGRS box (`box_ul_lonlat`, `box_lr_lonlat`, `box_km`), `box_centre` {lat, lon, avg_pct, slope_deg}, `best` {lat, lon, ground_m, avg_pct, vis_pct, slope_deg}, `search` {coarse_best_pct, refined_best_pct, mast_m, max_slope_deg, period, dem_res_m}. Story: "the middle of the region gets X %, this spot 4 km away gets Y %" |
| `mission_replay` | MissionReplay \| null | predicted vs actual mission ending (mission sites only) |
| `uncertainty` | Uncertainty \| null | P10–P90 event times and long-term % from NASA's DEM error clones (only sites with PGDA product 78 coverage: Shackleton rim now, C1 pending) |
| `meta` | `{engine, spice, generated_utc, build_s}` | provenance |

### Horizon

| Field | Type | Meaning |
|---|---|---|
| `n_az`, `az_step_deg` | 720, 0.5 | rays start at az 0 and step clockwise |
| `el_deg` | number[720] | terrain horizon elevation per ray (deg). Index `i` ↔ azimuth `i*0.5`. Interpolate linearly, wrapping at 360. |
| `block_dist_km` | number[720] | **ridge attribution** (default mast only): distance to the terrain sample that sets the horizon on that ray |
| `block_lat`, `block_lon`, `block_h_m` | number[720] | location and height of that sample |
| `ground_m`, `mast_m`, `near_res_m`, `far_res_m`, `near_km`, `far_km`, `sources` | | provenance |

A ray whose blocker is < 1 km away is local ground slope at the site, not a distant ridge.

### LongTerm

```json
{ "start_utc", "stop_utc", "step_s": 3600, "n",
  "sun":   { "avg_fraction_pct", "any_visible_pct", "full_disc_pct", "max_dark_h", "max_lit_h" },
  "earth": { ...same... },
  "both_any_pct" }
```

### Event

| Field | Type | Meaning |
|---|---|---|
| `target` | `"sun"` \| `"earth"` | |
| `kind` | `"first_light"` \| `"full_disc"` \| `"partial"` \| `"last_light"` | upper limb rises over terrain / lower limb clears terrain / lower limb sinks (partial disc begins) / upper limb sets (darkness) |
| `utc` | string | event time, refined to ~1 s with Brent's method |
| `az_deg`, `el_deg` | number | target direction at the event (geometric disc centre) |
| `horizon_el_deg` | number | terrain horizon elevation at that azimuth |
| `blocker` | object (default mast only) | `{phrase, feature, dist_km, az_deg, lat, lon, h_m}` — e.g. `"phrase": "rim of Shackleton crater"`, or `"local ground slope right at the site"` |

"Terrain sunset" = `sun` + `last_light`.

### Open-horizon events (`open_events`, added 13 Nov)

Top-level list, same window and fields as `events` (default mast) but against a flat **0° horizon**, i.e. what a tool without terrain assumes. There is no `blocker`, and `horizon_el_deg` is always 0. Also returned by the API `/site`. Use it for "terrain ends the light X h before the open horizon". The gap can be negative on summits, where the horizon dips below 0° (IM-2 on Mons Mouton: terrain sunset ~5.8 h *after* the open-horizon one). Before 13 Nov the dashboard derived this from the 3-h track, which is still a valid fallback for files without the field.

### Track

```json
{ "start_utc", "step_s": 10800, "n",
  "sun":   { "az_cdeg": int[n], "el_mdeg": int[n], "frac_pm": int[n], "ang_radius_deg" },
  "earth": { ...same... } }
```
Sample `k` is at `start_utc + k*step_s`. `frac_pm` is visible fraction × 1000 at the default 2 m mast. To redraw for another mast, combine az/el with that mast's `horizons[m].el_deg`.

### Sensitivity

```json
{ "res_m", "radius_px",
  "centre": {lat, lon, ground_m, avg_pct, vis_pct, bearing_deg, dist_m},
  "best":   {...same...},
  "gain_pp",                                   // best.avg_pct - centre.avg_pct
  "cells": [ {dr, dc, avg_pct, vis_pct}, ... ] }  // DEM-pixel offsets (row down, col right in polar-stereo grid)
```
Plain language: "Moving `best.dist_m` m toward bearing `best.bearing_deg` raises average illumination by `gain_pp` points."

### MissionReplay

| Field | Meaning |
|---|---|
| `landed_utc`, `end_utc`, `end_reason`, `end_note`, `sources` | the record (cite on screen) |
| `open_events` | (added 13 Nov) open-horizon events over the replay window; same shape as top-level `open_events` |
| `first_open_sunset_after_landing` | (added 13 Nov) the open-horizon counterpart of `first_terrain_sunset_after_landing`, or null |
| `track` | (added 13 Nov) same shape as the top-level Track, over `window`, for the animated replay. `step_s` is 1800 (30 min), coarsened in 30-min multiples so `n` <= 3000 (SLIM: 3600) |
| `expected` | `"sunset_after_end"` / `"sunset_near_end"` / `"sunset_before_end"` / `"multi_night"` / `"negative_control"` / `"tilt_limited"` (IM-1: the tipped lander lost power when the Sun left its one lit panel, days before terrain sunset) |
| `window` | [start, stop] of the replay |
| `events` | Sun + Earth events in the replay window (same shape as above) |
| `first_terrain_sunset_after_landing` | Event or null |
| `sun_frac_at_end` | visible solar fraction at the reported end time |
| `end_minus_sunset_h` | reported end − predicted sunset, hours (negative = mission ended before sunset) |
| `sunrises_after_landing` | UTC strings |

### Uncertainty

Built by `lunarnav.uncertainty.run(site_id, clone_file)` → `out/uncertainty/<id>.json`, merged by `scripts/precompute.py --merge-only`.

| Field | Meaning |
|---|---|
| `n_clones`, `inner_km`, `mast_m`, `window` | 100 clones, innermost ±2 km tier, 2 m mast, same planning window as `events` |
| `method`, `scope_note` | show on the Evidence page. Scope: height error within ~2 km only; distant-ridge error not sampled |
| `events[]` | `{target, kind, utc, p10_utc, p50_utc, p90_utc, spread_p10_p90_h, n_clones_matched, present_frac}`. `present_frac` < 1 means the event does not happen at all in some clones, typically a brief flicker of sunlight past a ridge ("this sunrise happens in 60 % of terrain versions"). Percentiles use only the clones where it happens. `utc` = baseline using the 5 m PGDA surface as inner tier (can differ by seconds–minutes from the 20 m `events`) |
| `longterm_sun` | `{baseline_avg_pct, baseline_vis_pct, avg_p10_p50_p90, vis_p10_p50_p90, period}` |

Results: median P10–P90 spread under 1 min at both sites; the widest events (Sun grazing a ridge) reach 8.2 h (Shackleton) and 9.5 h (C1). 13 of 116 Shackleton events and 2 of 74 C1 events are fragile (present in < 90 % of clones). Sites with uncertainty: Shackleton rim, Connecting Ridge C1. Long-term average illumination 83.5–84.1 % (P10–P90).

## 3. `out/validation_report.json`

```json
{ "generated_utc", "tests": { "<TestId>": { "<case>": { ...metrics..., "criterion": str, "pass": bool|null } } } }
```

| TestId | What it shows |
|---|---|
| `T1_ephemeris_vs_horizons` | max/median angular difference vs JPL Horizons (arcsec), 6 cases |
| `T2_terrain_vs_quickmap` | informational comparison with LROC QuickMap (agrees on Sun/Earth geometry, differs on local ridge) |
| `T3_longterm_vs_glaser` | 20-yr illumination vs Gläser et al. 2018, exact pixel / best within 60 m / 240 m grid / 100 km range |
| `T4_mast_height` | Connecting Ridge C1 at 0/2/10 m |
| `T5_spatial_vs_pgda` | 60-point RMSE vs PGDA product 69 maps (+ per-point table) |
| `T6_mission_endings` | predicted terrain sunset vs reported mission ends |
| `T7_negative_control` | IM-2 and IM-1: terrain sunlight remained at the reported end; both landers tipped over (orientation is outside the model) |
| `T8_physics` | sanity checks (polar Sun band, far side never sees Earth) |

`pass: null` = informational.

## 4. Edge states the data can produce

| Condition | How to detect | Suggested wording |
|---|---|---|
| Far side | `longterm.*.earth.any_visible_pct == 0` | "Earth never rises here (far side) — no direct radio link" |
| Sun never sets in window | no `last_light` sun events in `events` and `track.sun.frac_pm` all > 0 | "Sun never sets in this period" |
| Partial disc | 0 < frac < 1 | "Partial Sun (x% of disc)" |
| Earth limb only | earth frac small | "Earth limb only — may be optimistic for DSN links" |
| Local-slope blocker | `blocker.dist_km < 1` | "blocked by the ground slope right here" |
| Earth hidden by terrain | index `earth_blocked_by_terrain` | "Earth would be up, but terrain hides it from this exact spot" |
| Narrow uncertainty | `uncertainty.events[].spread_p10_p90_h` < 0.1 | "±1–2 min (DEM error near the site barely matters; the blocking ridge is far away)" |

## 5. Custom coordinates (planned, M8)

`GET /site?lat=..&lon=..&mast=2` → same shape as a per-site file (without `sensitivity` unless `?scan=1`). Latency target 1–2 s once the region's terrain is cached; first request in a new region can take longer (remote DEM reads).
